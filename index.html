How to use

  1. Push the record button
  2. Grant permission to share audio
  3. Select what you want to share and click Share
  4. When done sharing, push the stop sharing button on the bar at below or the stop button
Notes:
  • Try not to record video that is too long because if you run out of RAM it will cause error
  • Browser that works: Chrome, Edge
  • Microphone recording doesnt work because the security settings on CME forbids it
